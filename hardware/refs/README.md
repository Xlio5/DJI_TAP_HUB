# Hardware References

Reference designs to keep beside the project:

- Lichee Pi Zero core board schematic and PCB.
- Lichee Pi Zero Dock schematic and PCB.
- Allwinner V3s datasheet.
- Allwinner V3s user manual.
- Selected SPI NOR datasheet.
- Selected RJ45/magnetics datasheet.
- Selected SK6812/WS2812-compatible RGB LED datasheet.
- Selected USB ESD protection datasheet.

Do not blindly copy reference circuits. Preserve the proven Lichee Pi Zero
minimum system, USB, storage, and Ethernet topology, then review every net name,
pin mux, boot strap, recovery path, and power rail against the product board
requirements.
