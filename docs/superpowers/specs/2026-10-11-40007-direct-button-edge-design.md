# 40007 按键边沿直发设计

## 背景

V3S 通过 ADB 读取 Android 本机 `127.0.0.1:40007` 的 DJI DUML 数据，并将
`RC/0xAE` 按键状态融合后通过 RCMSG 发给 Android App。当前按键边沿需要依次经过
40007 接收线程、边沿队列、ADB 融合线程和主循环。虽然各层已有事件唤醒，线程调度和
通知合并仍可能增加最多两个 20ms 周期的下游延迟。

40007 是当前按键信息的唯一来源。本设计只压缩 40007 数据到达 V3S 后的延迟，不预测
按键状态，也不改变 DJI 上游的帧率。

## 目标

- 在 `v3s_adb` 输入模式下，40007 解码出的按键变化立即产生 RCMSG。
- 绕过 ADB 边沿队列、ADB 周期融合等待和主循环等待。
- 保留现有 50Hz 周期 RCMSG，继续刷新摇杆、模式和完整状态。
- 每个按下或松开边沿只即时发送一次，不通过旧队列重复回放。
- 记录从 40007 解码到 RCMSG 发送完成的软件延迟，支持实机验证。

## 数据流

正常状态帧继续走原有路径：

```text
40007 -> 更新最新40007状态 -> ADB融合线程 -> 主循环 -> 50Hz RCMSG
```

按键变化增加快速路径：

```text
40007解码 -> 检测按键变化 -> 融合最新getevent摇杆 -> 立即发送RCMSG -> Android即时边沿通道
```

快速路径只在当前输入模式为 `v3s_adb`、40007 状态有效且 RCMSG socket 可用时启用。
其他输入模式仍使用原有路径，避免非活动输入源影响 App。

## V3S 实现

40007 接收线程在持有状态锁时完成以下工作：

1. 合并新到达的 `RC/0xAE` 或 `SPECIAL/0x02` 状态。
2. 与上一份 40007 按键状态比较，判断是否出现按下或松开边沿。
3. 保存最新状态及其接收时间。
4. 边沿发生时复制当前 getevent 与 40007 状态，释放状态锁。

释放锁后，快速路径融合两路最新状态。若输入模式仍为 `v3s_adb`，使用现有原子 RCMSG
序号立即发送。网络发送不得在全局状态锁内执行。

40007 边沿不再进入 `g_adb_40007_edge_queue`。ADB 融合线程仍按原周期更新
`g_adb_rc`，但只处理 getevent 边沿队列。这样周期状态与快速边沿互不阻塞，也不会重复
发送旧边沿。

快速路径发送的状态必须使用与周期路径相同的融合函数和 RCMSG 编码函数。它不得修改
输出锁存状态，避免与主循环并发写锁存器；按键显示所需字段直接来自融合结果。

## 并发与顺序

- RCMSG 序号继续由 `g_rcmsg_seq.fetch_add()` 分配，快速帧和周期帧共享全局顺序。
- 快速路径在解锁后发送，避免 socket 或调度延迟阻塞 ADB 收包。
- 若快速帧与周期帧相邻，Android 按 UDP 到达顺序处理；周期帧读取的最新状态与快速帧
  一致，不应恢复旧按键值。
- 输入模式在融合后、发送前再次读取；模式已切换时放弃快速帧。

## 诊断

新增以下累计诊断字段到 `/tmp/rc_state.json`：

- `adb_40007_edge_tx_count`：快速边沿成功发送数量。
- `adb_40007_edge_tx_us`：最近一次从解码完成到 `sendto` 返回的耗时。
- `adb_40007_edge_tx_max_us`：进程启动以来最大耗时。
- `adb_40007_edge_tx_err`：快速边沿发送失败数量。

目标是 V3S 软件段 `adb_40007_edge_tx_us` 通常小于 3ms，最大值在系统正常负载下小于
10ms。该指标不包含 DJI 产生 40007 帧之前的等待，也不包含 Android UI 渲染时间。

## 测试与验收

- 单元测试验证按下、松开均被识别为边沿，相同状态不重复发送。
- 单元测试验证边沿快速路径使用融合后的 getevent 摇杆和 40007 按键。
- 单元测试验证非 `v3s_adb` 模式不触发快速发送。
- 构建并运行全部 Ubuntu CTest 与 Android 相关测试。
- 真机部署后连续按下、松开同一按键，确认 App 状态顺序正确且无重复闪烁。
- 从状态文件读回快速发送计数和延迟，确认按键操作时计数成对增长且软件段达到目标。

## 非目标

- 不提高 DJI 40007 的上游发布频率。
- 不预测尚未收到的按键状态。
- 不改变 50Hz 摇杆输出、CRSF/SBUS 输出或 Android 本地融合模式。
- 不引入新的按键锁存或延长按键显示时间。
